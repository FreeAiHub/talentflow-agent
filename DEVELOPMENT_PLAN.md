## 🎯 Цель десяти дней

Один сквозной сценарий, работающий на сервере без ручного запуска:

```
Djinni → парсинг → дедупликация → БД → LLM-скоринг → фильтр по порогу
      → генерация отклика → подтверждение человеком → уведомление в Telegram
```

**Критерий готовности:** каждое утро в Telegram приходит подборка горячих
вакансий с готовыми черновиками откликов, а `/health` на публичном URL
отвечает `ok`.

**Что осознанно НЕ делаем в эти 10 дней:** голосовые агенты, RAG, свой
фронтенд-дашборд, биллинг, мультитенантность. Это фаза 2 — см.
[`ROADMAP.md`](./ROADMAP.md).

## 🧱 Стек и решения

Выбор обоснован рисерчем от 23.09.2026 — отчёты в [`docs/research/`](./docs/research/).
Пока проверен только слой парсинга: решения по LLM, инфраструктуре и аутричу
опираются на общие практики, а не на проверенные цифры. Что закрыть и к какому
дню — в [`docs/research/README.md`](./docs/research/README.md).

| Слой | Решение | Почему |
|------|---------|--------|
| Язык | Python 3.12 | Уже заявлен в CI, есть в `requires-python` |
| Пакеты и окружение | **uv** | Lock-файл, установка в разы быстрее pip, уже используется в `Dockerfile` |
| API | FastAPI + Pydantic v2 | Уже в стеке, OpenAPI из коробки |
| Качество кода | **ruff** (линтер + форматтер) + **mypy** | Один инструмент вместо flake8+isort+black |
| Тесты | **pytest** + pytest-asyncio + respx | Async-эндпоинты и мок HTTP |
| Парсинг | `httpx` + `json.loads` по `application/ld+json` (Djinni); JobSpy — только фаза 2 | Листинг отдаёт массив `JobPosting` (schema.org) с полным описанием: HTML-парсер не нужен, второй запрос на карточку тоже. JobSpy не умеет Djinni |
| БД | SQLite на дни 1–7 → PostgreSQL 17 | Ноль инфраструктуры на старте, переезд до деплоя |
| ORM и миграции | SQLAlchemy 2.0 async + Alembic | Миграции обязательны до первого деплоя |
| Планировщик | APScheduler в процессе приложения | Не нужна отдельная инфраструктура очереди на 1000 задач/день |
| LLM | OpenRouter как шлюз + fallback на Groq/Cerebras, structured output в Pydantic | Бесплатный тариф OpenRouter — 50 запросов/сутки, этого мало: нужен второй провайдер. Groq даёт 1 000/сутки бесплатно |
| Наблюдаемость | Langfuse self-hosted + структурные логи JSON | Бесплатно, видно каждый вызов LLM и его стоимость |
| CI | GitHub Actions: ruff → mypy → pytest → docker build | Сейчас гоняется только `compileall` |
| Деплой | Coolify self-hosted на своём VPS (fallback — Railway Hobby $5/мес) | Coolify бесплатен навсегда, платить только за VPS. Railway Free непригоден: $1 кредита и 0 кастомных доменов |

Точные версии пакетов и цены держим в отчётах рисерча, а не здесь, чтобы не
дублировать быстро устаревающие цифры в двух местах.

## 🤖 Протокол работы агентов

Полные описания ролей и модели — в [`docs/AGENT-ROSTER.md`](./docs/AGENT-ROSTER.md).
Готовые промпты заданий — в [`prompts/agents/`](./prompts/agents/).

### Цикл одного дня

```
1. Постановка      человек/координатор выбирает день и задачи из этого плана
2. Реализация      Builder работает в ветке day-N/<slug>, коммитит по частям
3. Проверка        Verifier независимо проверяет DoD и пытается опровергнуть результат
4. Приёмка         человек смотрит diff и метрики, 15–20 минут
5. Слияние         PR → main, чекбоксы дня закрываются, план обновляется
```

### Правила, которые не обсуждаются

- **DoD или ничего.** Задача не закрыта, пока не выполнены все пункты DoD. «Почти работает» не считается.
- **Ветка на день.** `main` остаётся рабочей. Никаких прямых коммитов в `main` в обход проверки.
- **Проверяющий не автор.** Verifier — другая модель, чем Builder. Самопроверка не принимается.
- **Секреты не в репозитории.** Ни ключей, ни `.env`, ни токенов в промптах и коммитах.
- **Не выдумывать факты.** Цены, версии и лимиты — только со ссылкой на источник. Не проверено — так и пишем.
- **Дешёвая модель для рутины.** Массовые механические правки не гоняем через дорогую модель.

## 🔧 Ежедневная процедура

**Человек — 15–20 минут:**

1. **5 мин.** Открыть PR дня, посмотреть diff и метрики

3. **5 мин.** Смержить или отправить на доработку, обновить чекбоксы

## 📝 Шаблон коммита

```
<type>(<scope>): <краткое описание в императиве>

Почему это изменение нужно, а не что именно поменялось.

- Конкретное изменение
- Конкретное изменение

DoD: какие пункты дня закрыты

feat(parser): implement Djinni collection with dedup key

- Тесты на записанных фикстурах, без сети в CI

DoD: День 2 — 5/5
```
