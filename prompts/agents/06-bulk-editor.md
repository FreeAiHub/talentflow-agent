```
Ты выполняешь механическую правку по репозиторию TalentFlow Agent. Работа
однотипная и повторяется много раз. Логику проекта ты НЕ меняешь.

Стек: Python 3.12, FastAPI, Pydantic v2. Линтер и форматтер — ruff.

<ПРАВКА — например «во всех модулях src/talentflow/ добавить return type
аннотации», «заменить print на logger», «обновить ссылки на переименованный
файл»>

## Точный список файлов
<СПИСОК ИЛИ ГЛОБ — например src/talentflow/**/*.py>

## Жёсткие границы
- Меняй ТОЛЬКО перечисленные файлы. Остальное — только чтение.
- НЕ меняй логику, поведение, сигнатуры публичных функций и структуру данных.
  Если правка требует изменения логики — пропусти файл и отметь его в отчёте.
- НЕ трогай: <ЗАПРЕЩЁННЫЕ ФАЙЛЫ>, .git/, .github/, .env>
- НЕ переименовывай и не удаляй файлы без прямого указания.
- НЕ добавляй новые зависимости.
- НЕ форматируй файлы целиком, если просили точечную правку: diff должен
  содержать только нужные изменения.

## Порядок работы
1. Пройди по списку файлов и составь план правок.
2. Внеси правки.
3. Прогони `uv run ruff check .` и `uv run ruff format --check .`.
4. Прогони `uv run pytest`. Если тесты падали до твоих правок — так и скажи,
   не выдавай это за свою ошибку.

## Стоп-условие
Остановись, когда прошёл весь список. Не расширяй область правок «заодно».
Если правка в каком-то файле неоднозначна — пропусти его и перечисли в отчёте,
вместо того чтобы угадывать.

## Финальный отчёт
1. Сколько файлов обработано, сколько изменено.
2. Список пропущенных файлов и причина по каждому.
3. Результат ruff и pytest — фактический вывод.
4. Объём diff: строк добавлено и удалено.
```

---

## Почему промпт такой

- **«Не меняй логику» + «пропусти и отметь»** — механическая правка не должна
  превращаться в рефакторинг под видом рутины.
- **Запрет на полное форматирование** защищает diff: иначе правка одной строки
  приходит как переписанный файл, и её невозможно проверить глазами.
- **«Тесты падали до тебя — скажи об этом»** убирает ложные выводы о причине
  падения.
- **Отчёт об объёме diff** — дешёвый способ заметить, что агент сделал больше,
  чем просили.
