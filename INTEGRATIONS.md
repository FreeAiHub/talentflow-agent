## 🐳 Docker — варианты подключения

### Локально (настроено)
```bash
docker compose up --build
# API: http://localhost:8000 · Swagger: http://localhost:8000/docs
```
- [`Dockerfile`](./Dockerfile) — multi-stage на `uv` (быстрая сборка, компактный образ)
- [`docker-compose.yml`](./docker-compose.yml) — app + PostgreSQL 17

### Прод-деплой (современные варианты)

| Вариант | Что это | Когда выбирать |
|---------|---------|----------------|
| **Coolify** | self-hosted PaaS с открытым кодом, деплой из GitHub-репо в один клик | свой VPS (~5 €/мес), полный контроль, минимальная цена |
| **Railway** | managed PaaS, деплой из репо, PostgreSQL в один клик | скорость запуска, без своего сервера |
| **Fly.io** | контейнеры в глобальных edge-регионах | нужен EU-регион рядом с пользователями |
| **Render** | managed-хостинг + фоновые воркеры и cron | если нужен отдельный scraping-воркер |

**Рекомендация для MVP:** Coolify на недорогом VPS — там же поднимается n8n (см. ниже), один сервер на весь стек. Альтернатива «вообще без сервера» — Railway.

## 🤖 n8n — оркестрация автоматизаций

**n8n** — открытый конструктор workflow (self-hosted или облако). В связке с TalentFlow:

1. Cron → парсинг вакансий → скоринг → фильтр → запись в базу
2. Новая вакансия → генерация отклика → подтверждение человеком → отправка
3. Уведомления о лидах в Telegram
4. Связка с Instantly.ai и Botpress через готовые ноды

Взаимодействие с TalentFlow — через HTTP Request ноду к FastAPI (`/api/v1/...`, `/webhooks/...`).

## 📧 Instantly.ai — email-аутрич

**Instantly** — сервис холодных email-кампаний: разогрев доменов, последовательности писем, ротация ящиков. Подключение — REST API или готовая нода n8n. TalentFlow отдаёт в Instantly готовый список лидов с персонализированными текстами откликов.

## 💬 Botpress — чат-боты

**Botpress** — платформа AI-чат-ботов (сайт, Telegram, WhatsApp). Сценарий: конверсия ответивших лидов в диалог, квалификация, передача живому оператору. Официальная нода n8n — прямое подключение без кода.

## 🔒 Безопасность (план)

- **Секреты:** `.env` (в `.gitignore`), в проде — переменные окружения платформы; опционально SOPS
- **Вебхуки:** HMAC-подпись для Vapi/n8n
- **Rate limiting** на публичных эндпоинтах (slowapi)
- **Персональные данные:** минимизация хранения, GDPR (Португалия/ЕС)

## ✅ Валидация (план)

- Pydantic v2 схемы для всех входящих/исходящих данных (уже в `src/talentflow/models.py`)
- JSON Schema / structured output для ответов LLM
- Контрактные тесты вебхуков (Vapi, n8n)
- **Human-in-the-loop:** отклик уходит только после подтверждения человека (флаг `TALENTFLOW_HUMAN_IN_THE_LOOP`)
