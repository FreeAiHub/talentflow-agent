## Коммерческие материалы

**В этом репозитории их нет.** `CALL-PLAN.md`, `CLIENT-GUIDE.md`,
`CLIENT-PRESENTATION*.md` и презентации вынесены в
`~/Jarvis/projects/freeaihub/business-materials/`.

Причина в том, что они не описывают код: там прогнозы выручки (`MRR $15K → $85K`,
`ARR $180K → $1.02M`) и обещания доступности, которые репозиторий не
подтверждает. Рядом с технической документацией они читаются как описание
работающей системы.
