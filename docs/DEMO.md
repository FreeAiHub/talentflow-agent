# 🎬 Демонстрация TalentFlow Agent

> Сквозной сценарий: от пустой базы до утверждённого отклика. Одна команда,
> без настройки, без сети.

```bash
uv run python scripts/demo.py
```

---

## Два режима

| Режим | Команда | Что проверяет |
|-------|---------|---------------|
| **Оффлайн** (по умолчанию) | `uv run python scripts/demo.py` | проводку конвейера. Модель подменена заглушкой с фиксированной оценкой |
| **Живой** | `uv run python scripts/demo.py --live` | то же плюс настоящий Djinni и настоящая модель. Нужен ключ в `.env` |

Оффлайн-режим читает **записанную страницу Djinni** из `tests/fixtures`, поэтому
детерминирован, бесплатен и не зависит от доступности сайта. Он же может
крутиться в CI.

**Чего оффлайн-режим не показывает:** качества модели. Он доказывает, что части
соединены и гейт работает, а не что скоринг точен. Скрипт печатает это
предупреждение в конце, чтобы результат нельзя было принять за большее.

---

## Что происходит

```
1. Собираем вакансии          читаем записанную страницу Djinni
2. Собираем повторно          проверяем идемпотентность
3. Оцениваем                  скоринг по ICP, фильтр по порогу
4. Пишем черновик отклика     генерация + проверка на выдумки
5. Показываем уведомление     сообщение, которое уйдёт в Telegram, с кнопками
6. Гейт                       попытка отправить без подтверждения — отказ
7. Человек подтверждает       статус меняется на approved
8. Итог                       сводка из /api/v1/stats
```

---

## Что демонстрация доказывает

- Конвейер проходит целиком на пустой базе
- Повторный сбор не дублирует вакансии
- Порог отсечения работает
- Уведомление формируется с кнопками и без выдуманных фактов
- **Отправка без подтверждения человека невозможна** — шаг 6 это показывает
- После подтверждения отправка разрешается

## Чего не доказывает

- Точность скоринга (нужен живой прогон и размеченная выборка — День 5)
- Что сообщение доходит до Telegram (нужен токен бота)
- Что образ собирается (нужен Docker-демон)
- Что система работает на сервере (нужен VPS)

---

## Живой режим

```bash
cp .env.example .env
# положить бесплатный ключ Groq: TALENTFLOW_GROQ_API_KEY=...
uv run python scripts/demo.py --live --limit 5
```

Живой режим пойдёт на настоящий Djinni (один вежливый запрос) и потратит
несколько вызовов LLM. Результат будет зависеть от текущих вакансий на сайте.

---

## Ручной сценарий, без скрипта

Если нужно показать по шагам в терминале:

```bash
export TALENTFLOW_DATABASE_URL="sqlite:///./demo.db"
uv run alembic upgrade head

uv run python -m talentflow.parsers --source djinni --limit 15
uv run python -m talentflow.pipeline --parse-limit 0 --score-limit 5
uv run python -m talentflow.generators --limit 2 --min-score 0.6

uv run uvicorn talentflow.api.main:app --port 8000 &
curl -s localhost:8000/api/v1/stats
curl -s localhost:8000/api/v1/applications | head -c 400
curl -X POST localhost:8000/api/v1/applications/1/approve
```
