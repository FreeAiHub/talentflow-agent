## [0.1.0] — 2026-09-24

Первая версия. До неё репозиторий содержал документацию и не содержал
работающего кода: `JobSpyParser` и `QualityScorer` поднимали
`NotImplementedError`, каталога `tests/` не было. Разбор — в
[DEVELOPMENT_PLAN.md](docs/DEVELOPMENT_PLAN.md).

### Добавлено

- Конвейер `parse → score → draft → report` как точка входа командной строки.
- Парсер вакансий Djinni (`src/talentflow/parsers/djinni.py`).
- Хранилище: SQLAlchemy 2.0 async и четыре миграции Alembic.
- Цепочка провайдеров моделей с суточным бюджетом и кэшем ответов
  (`src/talentflow/llm/`).
- Проверка черновика на выдуманные факты (`src/talentflow/llm/guard.py`).
- Гейт подтверждения: отправка без решения человека запрещена кодом.
- Уведомления в Telegram с кнопками и дедупликацией доставок.
- Запуск по расписанию внутри процесса (`src/talentflow/scheduler.py`).
- REST-слой и вебхуки Telegram и Vapi.
- Каркас замеров качества скоринга с интервалами (`src/talentflow/evals/`).
- Демо от пустой базы до утверждённого отклика, офлайн по умолчанию
  (`scripts/demo.py`).

### Исправлено

Найдено первым живым прогоном на реальных вакансиях Djinni 24.09.2026. Ни один
из этих сбоев не видели 293 теста: живой путь модели в них не проходил.

- **Живой скоринг падал всегда.** `QualityScorer.score()` собирал результат как
  `ScoredVacancy(**vacancy.model_dump(), score=...)`, а `list_vacancies()`
  возвращает уже `ScoredVacancy` — поле `score` приходило дважды, и прогон
  заканчивался `TypeError: got multiple values for keyword argument 'score'`.
  Тесты передавали голый `Vacancy`, поэтому оставались зелёными. Регрессионный
  тест на `ScoredVacancy` добавлен.
- **Модель по умолчанию перестала отвечать.** `openrouter:openai/gpt-oss-120b:free`
  начал отдавать `404 This model is unavailable for free` — скоринг падал у
  любого, кто клонировал репозиторий. Заменена на проверенную живым прогоном;
  в `config.py`, `.env.example` и обоих README записано, как выбрать новую,
  когда и эта умрёт.
- **Модель, ответившая прозой, больше не роняет черновик.** Рассуждающие
  бесплатные модели иногда тратят весь ответ на размышления и не выдают JSON.
  `LLMClient.complete_json()` теперь показывает модели её же ответ и просит
  ответить заново — один раз, а не бесконечно.
- **Генератор больше не приписывает нам несуществующий опыт.** Промпт требовал
  «connect to concrete things we have done», а профиль отправителя по умолчанию —
  заготовка без конкретики. Модель закрывала пустоту выдумкой, и проверка на
  выдумки отклоняла каждый черновик: первый прогон дал `awaiting review: 0`.
  Добавлены правила 6 и 7 и пример честного короткого письма.
- **Проверка на выдумки перестала пропускать главный случай.** Черновик с
  фразой «We place Node.js/TypeScript engineers who have run production systems
  with real-time fan-out…» получал вердикт `ok`, хотя в профиле такого нет.
  После правки промпта тот же черновик получает `reject`.
- **Понятное предупреждение вместо молчаливого отказа.** Пока профиль
  отправителя остаётся заготовкой, конвейер пишет в лог, что черновики будут
  отклоняться и что нужно задать `TALENTFLOW_SENDER_PROFILE`.

### Изменено

- Документация приведена в соответствие с кодом. Прежние README и
  архитектурные документы описывали продукт, которого не было: 25+ моделей,
  10 000+ откликов, 99.9% uptime, Redis, Celery, Pinecone, Grafana.
- [ROADMAP.md](docs/ROADMAP.md) переписан: убраны `$1,000 MRR`,
  `5,000+ GitHub Stars`, «99% успешных вызовов AI-ядра» и «5% конверсия лидов» —
  ни одна из этих цифр не следовала ни из кода, ни из замеров.
- [prompts/README.md](prompts/README.md) переписан: он описывал промпты
  архитектуры, которой больше нет. Теперь названы три промпта, которые код
  действительно загружает.
- README честно называет пределы: бесплатные модели отвечают нестабильно,
  проверка на выдумки снижает риск, но не устраняет его, а профиль отправителя
  по умолчанию — заготовка.
- Правило: утверждение без доказательства — файла, теста или команды —
  в документацию не попадает. См. [CONTRIBUTING.md](CONTRIBUTING.md).
- Структура репозитория: документы собраны в `docs/`, в корне остались только
  общепринятые файлы.

### Удалено

- Сервисный каркас, который никогда не запускался: FastAPI-заготовка,
  `JobSpyParser` и `QualityScorer` с `NotImplementedError`.
- Архитектурные документы, описывавшие несуществующую платформу.

### Проверено

- **Тестов: 297**, все без сети (`uv run pytest -q`).
- **Живой прогон 24.09.2026:** пятнадцать вакансий собрано с Djinni за 2 с,
  восемь оценено живой моделью за 175 с, ранжирование осмысленное — Senior
  Backend 0.90 против Junior Support 0.08. Черновик с приписанным опытом
  отклонён проверкой на выдумки.
- **Что осталось непроверенным:** точность скоринга на реальных данных (baseline
  не снят), живая отправка в Telegram и сборка Docker-образа — нет токена и нет
  демона Docker.
